HTML

O HTML (HyperText Markup Language) é a linguagem de marcação padrão usada para criar e estruturar páginas na web. Ele funciona como o esqueleto de um site, organizando textos, imagens, links e outros elementos para que o navegador consiga exibi-los corretamente.
