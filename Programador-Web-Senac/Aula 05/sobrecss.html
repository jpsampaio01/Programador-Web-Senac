CSS

CSS (Cascading Style Sheets, ou Folhas de Estilo em Cascata) é a linguagem de estilo usada para definir a aparência visual de páginas web. Enquanto o HTML cria a estrutura básica do site, o CSS cuida das cores, fontes, espaçamentos e do layout.
